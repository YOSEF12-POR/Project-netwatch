# 🔐 نظام المصادقة والتسجيل - NetWatch

## 📋 ملخص النظام

تم بناء نظام مصادقة كامل وآمن يتضمن:

### ✨ الميزات المضافة:

1. **نموذج المستخدم المحسّن**
   - حقول جديدة: البريد الإلكتروني، حالة التحقق، حالة الحساب
   - تواريخ الإنشاء والتحديث التلقائية
   - معرّفات فريدة للأسماء والبريد

2. **خدمة المصادقة (AuthService)**
   - التحقق من صحة البريد الإلكتروني
   - التحقق من قوة كلمة المرور
   - التحقق من اسم المستخدم
   - التسجيل الآمن مع تشفير كلمات المرور
   - تسجيل الدخول مع معالجة جميع الأخطاء

3. **تحكم المصادقة (AuthController)**
   - تسجيل الدخول والخروج
   - التسجيل الجديد
   - لوحة التحكم (مع حماية من الوصول غير المرخص)
   - رسائل خطأ واضحة وودية

4. **واجهات المستخدم (Templates)**
   - تصميم حديث وسهل الاستخدام
   - ألوان جذابة وتخطيط منظم
   - رسائل خطأ وتنبيهات
   - دعم اللغة العربية الكامل
   - استجابة الصفحات على جميع الأجهزة

### 🌐 ميزات البيانات الحقيقية (v2.0)

5. **بيانات الإنترنت الحقيقية**
   - اختبار اتصال الإنترنت عبر ping لـ 8.8.8.8
   - عرض حالة الإنترنت (متصل/غير متصل) مع رسائل وصفية
   - تحديث تلقائي كل 30 ثانية

6. **بيانات حركة المرور الحقيقية**
   - جلب البيانات الحالية من واجهة ether1 في MikroTik
   - عرض Upload و Download بالـ Mbps
   - رسوم بيانية تفاعلية باستخدام Chart.js
   - بيانات تاريخية لآخر 7 نقاط زمنية

7. **عرض اسم الشبكة (Identity)**
   - جلب اسم الشبكة من MikroTik عبر `/system identity print`
   - عرض في الشريط الجانبي مع أيقونات ملونة
   - استخدام اسم الشبكة من قاعدة البيانات كبديل عند عدم الاتصال

## ⚙️ إعداد قاعدة البيانات

### 1. إنشاء قاعدة بيانات MySQL
```sql
CREATE DATABASE netwatch;
```

### 2. إنشاء ملف `.env` في جذر المشروع:
```
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=netwatch
SECRET_KEY=your-secret-key-change-in-production
```

### 3. التأكد من أن سيرفر MySQL يعمل

## 🏃 تشغيل التطبيق

```bash
# في الـ terminal
python run.py
```

التطبيق سيعمل على: `http://localhost:5000`⚠️ الواجهات المتاحة:
- `/login` - صفحة تسجيل الدخول
- `/register` - صفحة التسجيل الجديد
- `/dashboard` - لوحة التحكم (بعد تسجيل الدخول)
- `/logout` - تسجيل الخروج

---

## 📝 متطلبات كلمة المرور

- **الحد الأدنى**: 8 أحرف
- **حرف كبير واحد**: A-Z
- **حرف صغير واحد**: a-z
- **رقم واحد**: 0-9

**مثال على كلمة مرور قوية**: `Password123`

---

## 👤 متطلبات اسم المستخدم

- **الحد الأدنى**: 3 أحرف
- **الحد الأقصى**: 50 حرف
- **أحرف مسموحة**: `A-Z`, `a-z`, `0-9`, `_`

**أمثلة صحيحة**: `user123`, `john_doe`, `NetworkWatch`

## 🧪 اختبار النظام

### 1. **التسجيل:**
اذهب إلى `/register` وأنشئ حساب جديد

### 2. **تسجيل الدخول:**
اذهب إلى `/login` وقم بتسجيل الدخول

### 3. **لوحة التحكم:**
بعد تسجيل الدخول ستذهب تلقائياً إلى `/dashboard`

### 4. **تسجيل الخروج:**
اضغط على زر "تسجيل الخروج"
